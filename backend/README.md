# Receipt Tracker API (Backend)

The FastAPI backend turns receipt photos into structured JSON via Google Gemini.

> 📄 **Full Documentation:** Detailed API specifications, endpoints, environment variables, local testing, and deployment options have been moved to [**`docs/backend.md`**](../docs/backend.md).

## Quick Start

```bash
# Install dependencies
uv pip install -e .

# Set API key and start server
export GEMINI_API_KEY=your-key-here
python main.py
```

For full setup, configuration, and architecture details, see [**`docs/backend.md`**](../docs/backend.md).
